GitHub bağlantısı

Çözümlerin bu repoya commit edilir. Token sadece bu tarayıcıda saklanır, başka hiçbir yere gönderilmez (yalnızca api.github.com'a).

Token nasıl alınır?
  1. GitHub'da boş bir repo oluştur (ör. csharp-pratik). İçinde en az bir commit olsun; README ile oluşturman yeterli.
  2. Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Repository access: Only select repositories ve sadece bu repoyu seç.
  4. Permissions → Repository permissions → Contents: Read and write. Başka izin verme.
  5. Süre olarak 90 gün seç, token'ı kopyalayıp buraya yapıştır.

Varsayılan yol solutions/{cat}/{cls}.cs. Örnek: solutions/10-IleriCSharpDili/G41_NullableReferenceTypesVe.cs. Kullanılabilen alanlar: {cat} kategori klasörü, {cls} class adı, {slug} görev adı, {n} görev numarası.

Nasıl çalışılır

  1. Bir kez kur: dotnet new console -n Pratik, sonra her görevi Program.cs içine yazıp dotnet run ile çalıştır.
  2. Önce konu anlatımını oku, sonra görevi çözüme bakmadan yaz. Takılırsan önce ipucunu aç.
  3. "Çıktıda görmen gereken" maddeleri kendi ekranında doğrula. Tutmuyorsa nedenini bul.
  4. "Mülakatta" kutusundaki cümleyi kendi kelimelerinle sesli söyle.
  5. Ertesi gün aynı görevi sıfırdan yaz. İkinci seferde takılmazsan işaretle.

Repo yapısı

Tek repo: Cloudflare sadece public/ klasörünü yayınlar, çözümlerin solutions/ altında tek bir konsol projesi olarak derlenir.

  1. Sayfadaki editör her görevi kendi kategori klasörüne G41_... adlı static bir class olarak commit eder. Kodunu Run() metodunun içine, yardımcı tipleri sınıfın altına yazarsın.
